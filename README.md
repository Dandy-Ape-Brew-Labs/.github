# Dandy Ape Brew Labs — `.github`

This repository holds the **default community health files** for the
Dandy Ape Brew Labs organisation. Files here are inherited by every
repository in the org that does not define its own equivalent.

## Contents

| File | Purpose |
|------|---------|
| `PULL_REQUEST_TEMPLATE.md` | Default pull request template, applied org-wide |

## Notes

- A repository's own template always takes precedence over the default.
- Changes here apply to *new* pull requests/issues only.
- Keep it dignified. Tea is always ready.

*Maintained with utmost civility by the Society of Dandy Apes.* 🍵
